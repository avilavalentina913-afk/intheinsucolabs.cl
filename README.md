# intheinsucolabs.com

## Descripción

Sitio web informativo sobre los laboratorios del Instituto Superior de Comercio de Valparaíso, INSUCO.

El sitio permite conocer información sobre los cinco laboratorios del establecimiento, incluyendo la cantidad de computadores, sistema operativo y disponibilidad.

## Objetivo del proyecto

Crear un sitio web informativo, atractivo y adaptable a diferentes tamaños de pantalla para facilitar el acceso a la información de los laboratorios.

## Tecnologías utilizadas

* HTML5
* CSS
* Diseño Responsive

## Páginas del sitio

* Inicio
* Laboratorios
* Laboratorio 1
* Laboratorio 2
* Laboratorio 3
* Laboratorio 4
* Laboratorio 5
* Sobre mí
* Contacto

## Características

* Diseño responsive para computadores y dispositivos móviles.
* Información organizada de los cinco laboratorios.
* Navegación entre las diferentes páginas del sitio.
* Diseño desarrollado con HTML y CSS.
* Información individual para cada laboratorio.
